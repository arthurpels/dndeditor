# PRD: Редактор персонажей D&D (Flutter, MVP за 1 день)

**Версия:** 1.0 · **Дата:** 2026-07-03 · **Команда:** 4 человека · **Оценка:** 0.6–1.5

---

## 1. Обзор и цель

Мобильное приложение на **Flutter** для создания, просмотра, сохранения и
редактирования персонажей D&D 5e (правила издания **2014 года / PHB**).

**Цель на сегодня:** собрать работающий MVP, который проходит основной сценарий
целиком: *создать персонажа → сгенерировать характеристики и навыки по правилам →
посмотреть карточку → сохранить → открыть позже и отредактировать состояние.*
Плюс библиотека готовых персонажей и импорт/экспорт.

Всё оффлайн, локально на устройстве. Сервер, аккаунты и синхронизация — **не сегодня**
(см. раздел 13 «Усложнения»).

## 2. Границы MVP (Scope)

### Делаем сегодня (Must have)
1. **Экран-библиотека / главный** — список сохранённых персонажей + готовые персонажи + кнопки «Создать» и «Импорт».
2. **Мастер создания персонажа** (по шагам): имя → раса → класс → предыстория → генерация характеристик → распределение → навыки → обзор.
3. **Движок правил D&D 5e (2014)** — модификаторы, бонус мастерства, расовые бонусы, навыки, спасброски, HP, AC, инициатива (раздел 7).
4. **Карточка персонажа** — все характеристики, навыки, спасброски, боевые параметры, состояние (текущие HP).
5. **Сохранение / загрузка** локально (JSON). Возврат к персонажу и редактирование.
6. **Библиотека готовых персонажей** — 3–5 предсозданных, зашитых в ассеты.
7. **Импорт / экспорт** персонажа в JSON-файл.

### НЕ делаем сегодня (Out of scope)
- ❌ Заклинания, spell slots, книга заклинаний.
- ❌ Инвентарь, экипировка, деньги, encumbrance.
- ❌ Мультиклассы, фиты (кроме упрощённого Variant Human — опционально).
- ❌ Автоматический level-up с фичами класса выше 1 уровня (уровень задаётся вручную, влияет только на бонус мастерства и HP).
- ❌ Боевой трекер, инициатива в бою, состояния/condition-ы кроме HP.
- ❌ Сервер, авторизация, облако.
- ❌ Хоумбрю-редактор рас/классов.

> Всё из «НЕ делаем» — кандидаты в бэклог после защиты MVP.

## 3. Пользовательские сценарии

**S1. Создание нового персонажа.**
Пользователь жмёт «Создать» → проходит мастер (раса, класс, предыстория) → выбирает
метод генерации характеристик (стандартный массив / point buy / 4d6) → распределяет
значения → приложение автоматически применяет расовые бонусы, считает модификаторы,
навыки, спасброски, HP → выбирает навыки класса → видит обзор → «Сохранить».

**S2. Просмотр готового персонажа из библиотеки.**
На главном экране есть раздел «Готовые персонажи» → тап открывает карточку → можно
«Сделать копию себе» и редактировать.

**S3. Возврат к персонажу.**
Пользователь открывает сохранённого персонажа из списка → видит актуальное состояние →
меняет текущие HP / заметки / уровень → изменения сохраняются.

**S4. Импорт / экспорт.**
Экспорт: из карточки «Поделиться / сохранить в файл» → JSON-файл.
Импорт: на главном «Импорт» → выбор JSON-файла → персонаж добавляется в список.

## 4. Экраны

| # | Экран | Содержимое |
|---|-------|-----------|
| 1 | **Home / Библиотека** | Секция «Мои персонажи» (сохранённые), секция «Готовые», FAB «Создать», кнопка «Импорт». Карточка в списке: имя, раса/класс, уровень, HP. Свайп/долгий тап → удалить/дублировать. |
| 2 | **Мастер: Основа** | Поля: имя, выбор расы (dropdown/список), класс, предыстория. Короткое описание выбранного. |
| 3 | **Мастер: Характеристики** | Выбор метода (Standard Array / Point Buy / 4d6). Распределение 6 значений по STR/DEX/CON/INT/WIS/CHA. Показ итога с расовым бонусом и модификатором в реальном времени. |
| 4 | **Мастер: Навыки** | Чекбоксы навыков класса (выбрать N из списка), навыки от предыстории отмечены автоматически. Счётчик «выбрано X из N». |
| 5 | **Мастер: Обзор** | Полный предпросмотр карточки. Кнопка «Сохранить». |
| 6 | **Карточка персонажа** | 6 характеристик + модификаторы, бонус мастерства, 18 навыков (отмечены владения), спасброски, HP (макс/текущий, +/–), AC, инициатива, скорость, passive perception, предыстория/заметки. Кнопки «Редактировать», «Экспорт». |

Навигация: `Home → (push) Мастер (Stepper) → Карточка`. Стандартный `Navigator.push`, без go_router (для скорости).

## 5. Функциональные требования

- **FR1.** Приложение хранит список персонажей локально и переживает перезапуск.
- **FR2.** При создании применяются расовые бонусы к характеристикам автоматически.
- **FR3.** Модификаторы, бонус мастерства, навыки, спасброски и HP считаются движком по правилам 2014 (раздел 7), пользователь их не вводит руками (кроме генерации базовых значений).
- **FR4.** Пользователь выбирает навыки класса только из разрешённого списка и не больше лимита класса.
- **FR5.** Карточка отображает актуальное состояние; изменение текущих HP/уровня/заметок сохраняется.
- **FR6.** Готовые персонажи доступны из ассетов и открываются как обычные.
- **FR7.** Импорт/экспорт через JSON, формат совпадает с внутренним `toJson`.
- **FR8.** Валидация: нельзя сохранить без имени, расы и класса.

## 6. Модель данных

Один персонаж = один JSON. Храним **базовые** характеристики (до расовых бонусов),
итог считаем на лету — так редактирование расы не ломает данные.

```jsonc
{
  "id": "uuid-v4",
  "name": "Торин",
  "level": 1,
  "raceId": "dwarf",
  "classId": "fighter",
  "backgroundId": "soldier",
  "abilityMethod": "standard_array",       // как сгенерировали (для истории)
  "baseAbilities": {                        // ДО расовых бонусов
    "str": 15, "dex": 13, "con": 14,
    "int": 10, "wis": 12, "cha": 8
  },
  "skillProficiencies": ["athletics", "intimidation"],  // выбранные владения
  "savingThrowProficiencies": ["str", "con"],           // из класса
  "maxHp": 12,
  "currentHp": 12,
  "biography": "",
  "createdAt": "2026-07-03T10:00:00Z",
  "updatedAt": "2026-07-03T10:00:00Z"
}
```

Всё остальное (итоговые характеристики, модификаторы, бонус мастерства, AC,
инициатива, значения навыков) — **вычисляемые геттеры**, в JSON не хранятся.

## 7. Движок правил D&D 5e (2014) — спецификация

Это ядро проекта («перенос правил из книги»). Всё — чистые функции, покрываются юнит-тестами.

### 7.1 Модификатор характеристики
```
modifier(score) = floor((score - 10) / 2)
```

### 7.2 Бонус мастерства (по уровню)
| Уровень | 1–4 | 5–8 | 9–12 | 13–16 | 17–20 |
|---------|-----|-----|------|-------|-------|
| Бонус   | +2  | +3  | +4   | +5    | +6    |
Формула: `proficiencyBonus = 2 + ((level - 1) ~/ 4)`

### 7.3 Навыки (18) и их характеристики
| Характеристика | Навыки |
|----|----|
| STR | Athletics |
| DEX | Acrobatics, Sleight of Hand, Stealth |
| CON | — |
| INT | Arcana, History, Investigation, Nature, Religion |
| WIS | Animal Handling, Insight, Medicine, Perception, Survival |
| CHA | Deception, Intimidation, Performance, Persuasion |

```
skillValue = abilityModifier(навыка) + (proficient ? proficiencyBonus : 0)
```

### 7.4 Спасброски
`saveValue(ability) = modifier(ability) + (proficient ? proficiencyBonus : 0)`
Владения спасбросками берутся из класса (по 2 на класс).

### 7.5 Расовые бонусы к характеристикам (PHB 2014, базовые расы)
| Раса | Бонусы |
|------|--------|
| Human (обычный) | +1 ко всем шести |
| Dwarf | CON +2 |
| Elf | DEX +2 |
| Halfling | DEX +2 |
| Dragonborn | STR +2, CHA +1 |
| Gnome | INT +2 |
| Half-Elf | CHA +2 (+1 к двум по выбору — для MVP упростить до фикс. пары или пропустить выбор) |
| Half-Orc | STR +2, CON +1 |
| Tiefling | CHA +2, INT +1 |

> Сабрасы (High/Wood Elf, Hill/Mountain Dwarf и т.д.) — по желанию, если успеваем.

### 7.6 Классы (PHB 2014): кость хитов, спасброски, навыки
| Класс | Кость HP | Спасброски | Навыков | Список навыков на выбор |
|-------|:---:|----|:---:|----|
| Barbarian | d12 | STR, CON | 2 | Animal Handling, Athletics, Intimidation, Nature, Perception, Survival |
| Bard | d8 | DEX, CHA | 3 | любые |
| Cleric | d8 | WIS, CHA | 2 | History, Insight, Medicine, Persuasion, Religion |
| Druid | d8 | INT, WIS | 2 | Arcana, Animal Handling, Insight, Medicine, Nature, Perception, Religion, Survival |
| Fighter | d10 | STR, CON | 2 | Acrobatics, Animal Handling, Athletics, History, Insight, Intimidation, Perception, Survival |
| Monk | d8 | STR, DEX | 2 | Acrobatics, Athletics, History, Insight, Religion, Stealth |
| Paladin | d10 | WIS, CHA | 2 | Athletics, Insight, Intimidation, Medicine, Persuasion, Religion |
| Ranger | d10 | STR, DEX | 3 | Animal Handling, Athletics, Insight, Investigation, Nature, Perception, Stealth, Survival |
| Rogue | d8 | DEX, INT | 4 | Acrobatics, Athletics, Deception, Insight, Intimidation, Investigation, Perception, Performance, Persuasion, Sleight of Hand, Stealth |
| Sorcerer | d6 | CON, CHA | 2 | Arcana, Deception, Insight, Intimidation, Persuasion, Religion |
| Warlock | d8 | WIS, CHA | 2 | Arcana, Deception, History, Intimidation, Investigation, Nature, Religion |
| Wizard | d6 | INT, WIS | 2 | Arcana, History, Insight, Investigation, Medicine, Religion |

### 7.7 Генерация характеристик (3 метода)
- **Standard Array:** значения `[15, 14, 13, 12, 10, 8]`, пользователь раскидывает по характеристикам.
- **Point Buy:** 27 очков, старт 8, стоимость: 8→0, 9→1, 10→2, 11→3, 12→4, 13→5, 14→7, 15→9. Максимум 15 до расовых бонусов.
- **4d6 drop lowest:** кинуть 4d6, отбросить меньший, 6 раз; пользователь распределяет.

### 7.8 Производные боевые параметры
```
maxHp (уровень 1)   = max(кость_хитов_класса) + modifier(CON)
maxHp (уровень >1)  = кость + con_mod  +  (level-1) * (среднее_кости + con_mod)
                      // для MVP на уровне >1 допустимо ручное поле HP
armorClass (база)   = 10 + modifier(DEX)          // без брони; броня — вне MVP
initiative          = modifier(DEX)
speed               = скорость расы (Human/Dwarf 25–30 фт; для MVP 30, Dwarf 25)
passivePerception    = 10 + skillValue(Perception)
```

### 7.9 Предыстории (Backgrounds) — упрощённо
Для MVP достаточно 3–4 предысторий, каждая даёт 2 фиксированных владения навыком:
- Soldier → Athletics, Intimidation
- Acolyte → Insight, Religion
- Criminal → Deception, Stealth
- Sage → Arcana, History

> Владения от предыстории **суммируются** с владениями класса (дубли не считаются дважды).

**Статические данные (расы, классы, навыки, предыстории) храним как Dart-константы**
(compile-time safety, без парсинга ассетов). Готовых персонажей — как JSON в `assets/`.

## 8. Техстек и архитектура

**Flutter (stable), Dart.** Управление состоянием — **Provider (ChangeNotifier)**:
минимум магии, безопасно для команды в условиях одного дня.

### Пакеты (`pubspec.yaml`)
```yaml
dependencies:
  provider: ^6.1.2          # состояние
  shared_preferences: ^2.2  # хранилище (список JSON-персонажей)
  uuid: ^4.3                # id
  file_picker: ^8.0         # импорт JSON
  share_plus: ^9.0          # экспорт/поделиться JSON
  # google_fonts, flutter_svg — опционально для оформления
```

### Слои
```
lib/
  models/        character.dart, ability.dart, enums
  data/          races.dart, classes.dart, skills.dart, backgrounds.dart (константы)
  rules/         rules_engine.dart   ← вся математика 7.1–7.8, чистые функции
  repository/    character_repository.dart (shared_preferences: CRUD + import/export)
  state/         character_creation_controller.dart, library_controller.dart (ChangeNotifier)
  screens/       home, wizard/, character_sheet
  widgets/       stat_block, skill_row, hp_control ...
  assets/characters/*.json  ← готовые персонажи
test/            rules_engine_test.dart
```

**Договорённость №1 (критично):** модель `Character` и сигнатуры `RulesEngine`
фиксируются в **первый час** — остальные пишут против этого контракта параллельно.

## 11. Критерии приёмки (Definition of Done)

- [ ] Можно создать персонажа, пройдя мастер целиком, и он появляется в списке.
- [ ] Расовые бонусы, модификаторы, бонус мастерства, навыки, спасброски и HP считаются **автоматически и корректно** (сверка с PHB 2014 хотя бы для 3 комбинаций раса+класс).
- [ ] Навыки класса выбираются в пределах лимита; предыстория даёт свои владения.
- [ ] Карточка показывает все параметры из экрана 6.
- [ ] Персонаж сохраняется и доступен после перезапуска приложения.
- [ ] Текущие HP / уровень / заметки редактируются и сохраняются.
- [ ] Есть ≥3 готовых персонажа в библиотеке, они открываются.
- [ ] Экспорт даёт валидный JSON, импорт этого же файла восстанавливает персонажа.
- [ ] `rules_engine_test.dart` зелёный (модификаторы, бонус мастерства, навык с владением/без).

## 14. Риски и как их снять
| Риск | Митигация |
|------|-----------|
| Пытаемся впихнуть заклинания/инвентарь → не успеваем | Жёстко держим Scope (раздел 2). |
| Расхождение по модели данных между разработчиками | Контракт `Character`/`RulesEngine` фиксируется в первый час, файл заморожен. |
| Codegen (freezed/json_serializable) съедает время на настройку build_runner | Пишем `toJson/fromJson` руками. |
| Half-Elf / Variant Human «+1 по выбору» усложняют UI | В MVP — фиксированные бонусы или пропустить эти расы. |
| Некорректные правила → провал приёмки | Юнит-тесты движка + ручная сверка 3 персонажей с PHB. |
